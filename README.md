# 流亡黯道 字幕工坊

把流亡黯道（Path of Exile 1／2）的實況、攻略影片，自動做成**繁體中文 SRT 字幕**。
專為中英混雜的遊戲用語調整過：`POB`、`DPS`、`Build` 這類英文術語維持原樣，遊戲專有名詞用詞庫自動校正，斷句習慣模仿剪映成品（單行短句、平均約 10 字）。

## 特色

- **中英混雜辨識**：faster-whisper large-v3，每一段自動判斷中文或英文
- **遊戲詞庫校正**：內建約一萬條流亡黯道 1／2 官方詞條與常見錯字對照
- **自然斷句**：用實際剪映成品字幕訓練的斷句模型，專有名詞、數字不會被拆開
- **待確認清單**：工具沒把握的地方另外列出來，對照原音快速檢查
- **個人詞庫**：加入你自己常被聽錯的詞、你的名字和口頭禪
- **自動更新**：開啟時會檢查 GitHub 上的新版本，按一下就能更新

## 安裝（Windows）

1. 在這個頁面按綠色的 **Code → Download ZIP**，解壓縮到任何資料夾（例如桌面）。
2. 雙擊 **`一鍵安裝並啟動.bat`**。
   - 第一次執行會自動安裝 Python、辨識套件、ffmpeg，需要幾分鐘。
   - 如果中途要你「關閉視窗再雙擊一次」，照做即可。
   - 完成後桌面會出現「流亡黯道字幕工坊」捷徑。
3. 第一次產生字幕時會下載辨識模型（約 3GB），之後就不用再下載了。

> 有 NVIDIA 顯示卡會快很多；沒有也能用，只是比較慢。

## 使用方式

1. 把影片、音訊或 SRT **拖曳**到「① 選擇影片」框框裡。
2. 檢查「② 字幕設定」（滑鼠移到項目名稱上會有說明）。
3. 按 **開始產生字幕**，等進度球滿。
4. 輸出在影片旁邊的 `字幕輸出` 資料夾：
   - `xxx 字幕.srt`：匯入剪映、Premiere、達文西
   - `xxx 字幕.review.txt`：需要你聽原音確認的地方

| 丟進來的檔案 | 做什麼 |
|---|---|
| 影片／音訊 | 語音辨識 → 詞庫校正 → 斷句 → SRT |
| `.srt` | 只校正錯字，保留原本時間軸 |
| `xxx 原文.json` | 不重新辨識，用新的詞庫與斷句重做一次 |

## 個人詞庫

按設定裡的 **個人詞庫**，一行一條：

```
錯誤寫法=正確寫法
我是萌萌=我是惡魔貓
?紅毛=惡魔貓        ← 前面加 ? 只列進待確認清單，不自動改
```

右邊的「斷句保護」可以填不想被斷開的詞。
個人詞庫存在 `個人術語補充.csv`、`個人術語保護.txt`，**自動更新不會覆蓋**。

## 自動更新

- 開啟工具時會自動檢查新版本，有新版會出現提示列，按「立即更新」即可。
- 更新前，舊檔會備份到 `_backup\` 資料夾。
- 以下檔案永遠不會被更新覆蓋：個人詞庫、`使用者設定.json`、輸出的字幕檔、`.venv`。
- 介面打不開時，可以雙擊 `手動更新.bat`。

## 常見問題

**字幕比聲音早／晚出現？** 調整「字幕延後」：太早就調大，太晚就調小（預設 +0.20 秒）。

**一直重複同一句？** 背景音樂大或很吵時，可以把辨識模型換成「穩定（large-v2）」。

**出現錯誤？** 按「複製錯誤訊息」，到 [Issues](https://github.com/DevilCat-POE/poe-subtitle/issues) 回報。

## 指令列用法

```
.venv\Scripts\python.exe poe_subtitle.py 影片.mp4 --out-dir 字幕輸出
python poe_subtitle.py --help
```
